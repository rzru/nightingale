This page provides a complete reference of all keyboard shortcuts and gamepad mappings.

## Menu Navigation

In the main menu, sidebar, and settings screens:

- **Arrow keys / D-pad**: Move focus between items
- **Enter / A button**: Select the focused item
- **Escape / B button**: Go back or close overlays
- **Tab**: Switch between sidebar and main content area
- **Type any text**: Filter/search the song list
- **Actions button**: Open bulk actions for the current filtered list

## During Playback

While a song is playing:

- **Space / Start**: Pause or resume playback
- **Escape / B**: Exit back to the song menu
- **G**: Toggle guide vocals on/off
- **+ / -**: Adjust guide vocal volume
- **T**: Cycle through background themes (shaders, video, source)
- **F**: Cycle through Pixabay video flavors (Nature, Underwater, Space, City, Countryside)
- **M**: Toggle microphone for pitch scoring during solo playback
- **N**: Switch to the next available microphone during solo playback
- **R**: Toggle mic monitoring (live monitor during playback)
- **F11**: Toggle fullscreen

## Song List and Details Controls

Use the song-list toolbar to switch between table and grid views, filter by analysis status or lyric source, open bulk actions, and open the playback queue. Select a row or card to open its details sidebar before playback.

Each row and card also has a quick-action button, and right-clicking it opens a menu: analyze an unanalyzed song or jump straight to providing lyrics, add a song to the top or bottom of the queue, or play it solo or in multiplayer without opening the sidebar first.

For an analyzed song, the details sidebar provides:

- **Play**: start solo playback with the selected settings
- **Play multiplayer** (people button): assign two to four singers, profiles, and microphones before playback
- **Add to queue**: save the current key and tempo choices in the set list
- **Tempo**: adjust playback speed in small steps
- **Key**: transpose to a more comfortable vocal range
- **Lyrics and language actions**: edit or replace lyrics and correct the song language
- **Analysis actions**: start, cancel, retry, or refresh available analysis steps

In table view, select a sortable column header to add it as the next sort priority. Select it again to switch from ascending to descending, then once more to remove it. Priority numbers beside active headers show the order used and remain saved between sessions.

Bulk actions apply to the current filtered list. Available actions include analysis and cancellation, metadata refresh, lyric realignment, reanalysis, and cache deletion.

## Playback Queue and Session Mode

Open **Playback Queue** from the song-list toolbar to review the set list. The first song is marked **Next up**. Drag a song's reorder handle to move it. With a keyboard, focus the handle, press Space or Enter to pick it up, move it with the Arrow keys, then press Space or Enter to drop it; press Escape to cancel.

You can remove individual songs, choose **Play Queue**, use the people button to play the queue in multiplayer, or clear the full queue after confirmation. A multiplayer lineup stays active for subsequent queued songs, and the results screen lets you change players before starting the next song.

In **Settings → Playback**, choose **Session mode** to keep the menu available while playback runs in a dedicated desktop window or browser tab. **Classic mode** replaces the menu with playback in the current window. See [Multiplayer](/docs/multiplayer/) for player setup and scoring behavior.

## Skip Buttons

During playback, on-screen skip buttons appear for intro and outro sections. These can be activated with Enter/A or clicked.
